\# Final Project Report

\## Mahasigma Car Rental Information System



\*\*Project completion date:\*\* 12 November 2026



\## 1. Project Overview



Mahasigma Car Rental is an information system project designed to support the management of car rental operations. The system provides functionality for managing users, staff, branches, vehicle data, rental transactions, and related administrative activities.



\## 2. Implemented Functionality



The project repository includes the following functionality:



\- Role-based authentication and session management.

\- Branch and vehicle type management.

\- Vehicle data management and availability filtering.

\- Member registration and administrative member management.

\- Staff management and branch assignment.

\- Rental transaction creation and transaction searching.

\- Vehicle return recording.

\- Transaction history for administrative users and members.

\- Vehicle condition and rental price recap data.

\- Administrative settings and interface styling.
